# ⚡ simul8r4brokahmf

**Learn to code with Bro KAHMF — your personal coding sensei with zero judgment and max hype.**

A gamified, personality-driven coding dojo that makes people **WANT** to learn. Built for everyone — absolute beginners to seasoned devs.

---

## 🎮 Features

### 📚 21 Lessons Across 5 Tracks

| Track | Lessons | Description |
|-------|---------|-------------|
| 🐍 **Python Path** | 12 lessons | From zero to Python pro |
| 🟨 **JavaScript Journey** | 2 lessons | Make the web your playground |
| 📝 **Pseudo Prep** | 1 lesson | Logic without syntax |
| 🌟 **Challenge Mode** | 4 lessons | Hard problems for spicy times |
| 💡 **Quiz Corner** | 2 lessons | Test your CS knowledge |

### 🎯 Lesson Types
- **code** — Write functions that pass tests
- **debug** — Find and fix the bugs in broken code
- **quiz** — Answer CS theory questions (no code needed!)

### 🏅 Gamification
- **XP & Levels** — Level up as you learn (1-100)
- **🔥 Streaks** — Keep your coding streak alive!
- **🏆 Achievements** — Unlock badges for milestones
- **👑 Titles** — Earn titles from "Script Kiddie" to "The KAHMF Himself"
- **💬 Bro KAHMF** — Encouraging messages, reactions, and wisdom

### 🎨 Accessibility
- Dark / Light / High Contrast themes
- Adjustable font size
- Reduce motion option
- Screen reader friendly (ARIA labels, semantic HTML)
- Full keyboard navigation

### 🌐 Multi-Language
- 🐍 **Python** — Full sandboxed execution
- 🟨 **JavaScript** — Node.js execution
- 📝 **Pseudocode** — Write logic in plain English

## 🚀 Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Start the server
uvicorn app.main:app --port 3000

# Open in your browser
open http://localhost:3000
```

Or with npm:
```bash
npm start
```

## 🏗️ Architecture

```
app/
├── main.py           ← FastAPI server (10+ endpoints)
├── lab_injector.py   ← 21 lessons, 5 tracks, quizzes & debug challenges
├── executor.py       ← Multi-language sandboxed execution
├── state.py          ← Gamified state: XP, streaks, levels, achievements
├── achievements.py   ← 15 achievements, 14 titles, Bro KAHMF personality
├── languages.py      ← Python, JavaScript, Pseudocode runners
└── static/
    └── index.html    ← Full gamified frontend (single-page app)
```
