# noHXW — No Hardware, No Problem

**Distributed Infrastructure Simulation Engine**

A gamified, full-stack learning platform that takes you from **Green Bean** to **Principal Engineer** and beyond. No hardware required — just your curiosity and a browser.

---

## 📚 21 Lessons Across 5 Tracks

| Track | Lessons | Description |
|-------|---------|-------------|
| 🐍 **Python Path** | 16 | From zero to algorithmic problem-solving |
| 🟨 **JavaScript Journey** | 9 | Web fundamentals and array manipulation |
| 📝 **Pseudo Prep** | 6 | Logic without syntax — perfect for absolute beginners |
| 🌟 **Challenge Mode** | 4 | Interview-style algorithm problems |
| 💡 **Quiz Corner** | 2 | Computer science theory and web knowledge |

### Lesson Types
- **code** — Write functions that pass test cases
- **debug** — Find and fix bugs in broken code
- **quiz** — Answer CS theory questions

## 🚀 Quick Start

```bash
# Install dependencies
pip install fastapi uvicorn python-multipart

# Start the server
uvicorn app.main:app --port 3000

# Open in your browser
open http://localhost:3000
```

Or with npm:
```bash
npm start
```

## 🏛️ Architecture

```
noHXW/
├── app/
│   ├── main.py              FastAPI server (10+ endpoints)
│   ├── lab_injector.py      21 lessons, 5 tracks, 3 lesson types
│   ├── executor.py          Multi-language sandboxed execution

│   ├── achievements.py      15 achievements, 14 career titles, progression messages
│   ├── languages.py         Language runtimes and configurations

│       └── index.html       Full gamified single-page frontend
├── AGENTS.md                Agent instructions and architecture overview
├── package.json             npm scripts
└── requirements.txt         Python dependencies
```
