# ⚡ noHXW — No Hardware, No Problem

**Distributed Infrastructure Simulation Engine**

*Because buying hardware is for people with money. We emulate.* 🏴‍☠️

---

A gamified, personality-driven coding dojo that makes people **WANT** to learn.
Emulates the infrastructure you can't afford so you can learn anyway.

## 🎮 Features

### 📚 21 Lessons Across 5 Tracks

| Track | Lessons | Description |
|-------|---------|-------------|
| 🐍 **Python Path** | 12 | From zero to Python pro |
| 🟨 **JavaScript Journey** | 2 | Make the web your playground |
| 📝 **Pseudo Prep** | 1 | Logic without syntax |
| 🌟 **Challenge Mode** | 4 | Hard problems for spicy times |
| 💡 **Quiz Corner** | 2 | Test your CS knowledge |

### 🎯 Lesson Types
- **code** — Write functions that pass tests
- **debug** — Find and fix the bugs in broken code
- **quiz** — Answer CS theory questions (no code needed!)

### 🏅 Gamification
- **XP & Levels** — Level up as you learn (1-100)
- **🔥 Streaks** — Keep your coding streak alive!
- **🏆 Achievements** — Unlock badges for milestones
- **👑 Titles** — From "Script Kiddie" to "The KAHMF Himself"
- **💬 Bro KAHMF** — Personality-driven reactions

### 🌐 Multi-Language
- 🐍 Python — Full sandboxed execution
- 🟨 JavaScript — Node.js execution
- 📝 Pseudocode — Write logic in plain English
